# NLP技術面接用デモ（事前整備版）

## 起動

Python 3.11以上を推奨。プロジェクト直下で実行します。

```powershell
python -m pip install -r requirements.txt
python demo.py --check
python demo.py
```

サーバー起動後は、表示される `http://127.0.0.1:8765/` などのURLをブラウザで開きます。終了はターミナルで `Ctrl+C` です。

- `python demo.py --check`：同じ固定の架空データで2回評価を実行し、結果が一致するか確認。ブラウザは起動しません。
- `python demo.py --no-browser`：自動ブラウザ起動を抑制。
- `python demo.py --port 8888`：任意のポートを指定。
- `python -m pytest -q`：デモと既存サンプルの自動テスト。

## 画面で説明する流れ

1. **問い**：「問い合わせ文章を `billing`（請求）か `technical`（技術）に自動分類したい」
2. **入力**：画面のサンプル英文を選ぶか、500文字以内の英文を入力して分類。
3. **手法**：同じ訓練/テスト分割で `CountVectorizer`（BoW）と `TfidfVectorizer`（TF-IDF）を比較。分類器は両方 `MultinomialNB`。
4. **評価**：Accuracy、macro Precision・Recall・F1、混同行列を見る。誤分類があれば具体例を確認。
5. **限界**：この数値は少量の合成英文データ・固定分割の値であり、一般の問い合わせや日本語に対する性能の証拠にはならない。

注意：画面上の比較は、2つの **特徴量表現** の比較です。BoW対TF-IDFの効果を厳密に主張するには、同じ分割だけでなく複数シード、別データ、信頼区間等の検証が必要です。

## 実装・担当範囲

| ファイル | 役割 |
|---|---|
| `examples/support_ticket_comparison.py` | 既存の前処理・BoW/TF-IDF＋MultinomialNB比較。変更せず利用 |
| `demo_data/sample_tickets.csv` | デモのためにAI支援で新規生成した48件の架空英文。本人の演習データではない |
| `demo_model.py` | 既存処理と同一構成のモデルを画面用に学習し、指標・誤分類・入力文の予測を返す |
| `demo.py` | ローカルHTTPサーバー、入力バリデーション、実行オプション。外部通信・実運用機能なし |
| `demo_web/` | 入力欄、モデル比較、混同行列、誤分類の表示 |
| `tests/test_demo.py` | 再現性・API動作・入力検証の自動テスト |

本デモの追加コード、UI、説明資料、テストおよび架空データは生成AIが整備しました。本人の自然言語処理学習における演習・思考・実験と混同しないでください。
